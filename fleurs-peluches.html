Fleurs & peluches

Les fleurs et les peluches sont parmi les objets les plus connus des voyages dans Torn. Chaque destination possède ses propres objets et leur valeur sur le marché peut varier.

🌍 Le principe

Voyage dans un pays, achète ses objets spécifiques, puis rapporte-les à Torn pour les vendre ou les conserver afin de compléter une collection du musée.

⚠️ Attention aux prix

Les prix d'achat indiqués ici sont les prix fixes des vendeurs étrangers. Le prix de revente sur le marché évolue constamment.

💰 Rentabilité

La méthode de calcul complète (marge par emplacement, durée des voyages) est sur la page Gagner de l'argent. Voici ce qui compte pour les fleurs et les peluches :

1. Prix d'achat Le prix fixe payé à l'étranger.
2. Prix de vente Le prix auquel tu peux réellement vendre l'objet.
3. Taxe du marché L'Item Market applique une taxe de vente de 5 %.
4. Coût du voyage Le coût du déplacement doit entrer dans ton calcul.
5. Temps de voyage Une grosse marge n'est pas forcément meilleure si le voyage est très long.
🏪 Tu possèdes un Bazaar ?

Les ventes réalisées dans ton Bazaar ne sont pas soumises aux 5 % de taxe de vente de l'Item Market. Cela peut améliorer directement ta marge, surtout pour les objets à faible marge.

Exemple : tu achètes un objet 10 000 $ et tu le revends 15 000 $, soit 5 000 $ de marge brute. Sur l'Item Market, la taxe retire environ 750 $ (5 % de 15 000 $) ; dans ton Bazaar, rien n'est retiré.

🏛️ Le musée

Après avoir terminé la formation History Studies, un set complet de peluches ou de fleurs exotiques peut être échangé contre des points du musée.

🌸 Set de fleurs exotiques Les 11 fleurs exotiques forment un set complet.
🧸 Set de peluches Les peluches étrangères et celles disponibles à Torn composent le set complet.
💡 Ne vends pas automatiquement tout.

Si tu cherches à compléter un set, conserver certains objets peut être plus intéressant que de les vendre immédiatement : un objet peut avoir une valeur supplémentaire pour un collectionneur.
